# Contributing

This project is a work in progress and not yet released. Contributions, bug reports and ideas are welcome.

## Terms

- By submitting a contribution (a pull request, a patch, text or code in an issue), you agree it is licensed under the same terms as the project, the
  [PolyForm Noncommercial License 1.0.0](LICENSE), **and** you grant the maintainer (Davi de Souza) the right to relicense your contribution as part of the
  project (for example to offer a commercial licence alongside the noncommercial one). You confirm that you have the right to contribute it.
- Do not contribute anything you do not have the right to share: no game files, car models, textures, templates, logos or artwork, and no code copied from
  sources whose licence does not allow it.

## Before you start

- Read `AGENTS.md` and `docs/TODO.md` (section 0). Keep commands few, outputs short, and placement by named panel.
- `npm install` then `npm test`. Tests must not need game data.
- Mark claims in docs as verified (by a run you can describe) or unverified.
