# Session log: 2026-10-21 (first session)

Written so that nothing from this session lives only in a conversation. Read `docs/TODO.md` for the plan; this file is the story and the reasoning.

## The ask, and how it evolved

- **Origin:** the owner's brother tried Hermes Agent (local Qwen ~27B) with GIMP and Blender MCPs to put a team livery on a mod car. It failed.
  The owner wants a repo that makes this work for agents, local models first, later cloud models, later other liveries, asks and vehicles.
- **Use case #1:** "T. Thiele #71 Monster Energy Ultra" on the RSS GT-M Protech P92 F6 (`rss_gtm_protech_p92_f6`), from 15 reference photos
  (Gran Turismo 7 renders) and logos from the web. A previous green "croc" livery on the same car is the template.
- **Working agreement:** Sonnet drives; a stronger advisor weighs in on big decisions; Haiku subagents for bounded routing work
  (research sweeps, QA). Every claim in docs is marked verified or unverified.

## What we decided (and why)

1. Local models first; whether an LLM or an image model is best is to be **benchmarked**, not assumed.
2. MVP: edit a livery on the same car; cross-car transfer is the second goal.
3. liverykit (MIT, single author, young) is the engine, pinned; this repo is the agent layer. liverykit's MCP is not used (it keeps placement with a human).
4. The core is deterministic code with **few high-level commands** and skills; GIMP/Blender are optional, not core.
5. Prepare once (car pack), run light; name panels not pixels; one image per look; ask before anything outward.
6. Hermes trials are **parked** until a Haiku run does the use case well enough (`docs/milestones.md`).

## What we learned (verified unless marked)

- The kn5 (60 MB) parses and is not encrypted; liverykit built a profile of 826 panels, 69 on the body atlas; a headless render takes ~2 s per view.
- The modder's PSD gives UV, AO and sticker layouts cheaply (ag-psd, ~2.5 s) but its `ALPHA` layer is the previous livery's graphics, not a mask. The
  user's cutouts image is the atlas at 541 px height with ~92 px cropped off the left.
- Side/orientation: `right_*` panels are the atlas top strip (rotation 180), `left_*` the bottom (0); mirrors are `left_mid_lower_2`/`right_mid_lower_2` (probe-verified).
- Door plates are a separate cut-out texture (own halves per door, a roughly square card at each end); until overridden they render dark grey.
- Texels are square at the texture's real aspect ratio, so logos do not stretch if the canvas keeps it.
- Hermes' own skill loader needs only `name` (<= 64) and `description` (<= 1024).
- Not verified: loading any exported skin in the game; `ui_skin.json` key names; non-power-of-two sizes beyond the P92 body; the 2048x640 `Door_Plates.dds`.

## Mistakes worth remembering

- I treated the **subtle grey ink art** as "no asset, skip". It is what makes the livery read as the Monster can artwork. The kit now has an analysis step
  (`ac-analyze`) that forces such layers to be listed and planned, and the brief refuses to move on while a subtle layer has no element.
- I placed logos from a list instead of from the photos; I skipped the door plate texture; I mislabelled two reference views (the compare sheet caught it).
- Patches written through shell-quoted JS silently lost backslashes (regexes) twice, and a long chained shell command with several heredocs failed to parse:
  write files with the file tools, and keep patch scripts in files.

## The owner's feedback (kept, close to their words)

- The first pass was "the right direction but sub par to the goal".
- Missing: "the discreet gray decals against the almost white skin" that give the livery its resemblance to the Monster can artwork; "reflect on that
  as well, maybe as part of the agent analysis to get the inspiration and artwork detail". This car art is harder because of those details.
- "Be careful not to overlay some logos on top of others unless explicitly shown or instructed from the style and art that it's mirroring, or the human instruction."
  (Now enforced by the `decal` overlap guard; `--overlap` is the exception.)
- "Park Hermes trials because it's sub par. My milestone is: when we can get Haiku to do it good enough, then we'll trial with Hermes."
- "Start mapping skills, order of things, requirements, tools, so this can be streamlined from the repo so local models don't struggle in the sense that they need to
  relearn and re-figure everything out. I want the repo to make a real difference." (-> `docs/workflow-map.md`, `cars/<id>/notes.md`, `eval/`.)
